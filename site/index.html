How it works

Check what moves before migration.

Use the report to find metadata that needs an export, a rendered copy, or a manual check.

  1. 01

    Scan your folders

    Give the CLI a source folder, a target folder, and an optional Lightroom catalog.

  2. 02

    Read the report

    See embedded, sidecar, catalog-only, and unsupported metadata in one checklist.

  3. 03

    Verify a sample

    Check the listed photos after importing them into your destination application.

Install and scan

Run the CLI on a copy of your library.

Keep originals and your Lightroom catalog until you verify the destination sample.

migration-check.sh
$ edit-portability-map scan \
  --catalog "Lightroom Catalog.lrcat" \
  --source ./Originals \
  --target /mnt/archive/Photos \
  --target-app immich \
  --json-report portability.json

What this CLI does not do

It does not translate Lightroom develop recipes. Render finished versions that you need to preserve.
