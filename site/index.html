Survey method / 01–03

A field map, not a magic converter.

The tool makes ownership visible. It never promises that one application's look can be translated into another's recipe.

  1. 01

    Inventory the layers

    Open a Lightroom catalog in SQLite read-only mode. Parse adjacent XMP as text. List source and target names without decoding photos.

  2. 02

    Map support

    Classify each observed category by its real home and compare it with Immich, darktable, digiKam, or a generic file workflow.

  3. 03

    Prove a sample

    Work blockers first, then import a deterministic cross-section. Keep every original until the destination passes inspection.

$ edit-portability-map scan \
  --catalog "Lightroom Catalog.lrcat" \
  --source ./Originals \
  --target /mnt/archive/Photos \
  --target-app immich \
  --json-report portability.json

The honest boundary

Lightroom's develop recipe and history are proprietary application state. This tool flags them; it does not fake a conversion. Render critical finished versions, preserve originals, and keep a catalog backup.
