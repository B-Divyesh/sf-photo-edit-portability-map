Privacy for local photo inventory.

CLI data

The CLI reads paths, file names, XMP text, and an optional Lightroom catalog. It writes only reports that you name outside the scanned folders.

Sample data

The website demo uses bundled sample data. It stores only the selected target profile under a demo-only browser key. Reset returns to Immich. Leaving the demo removes the key.

License storage

If you paste a license or return from checkout, the browser stores that token and its daily verdict. The token is sent only to Sociobot for license verification. Clear this site’s storage to remove it.

Website requests

The site has no analytics, advertising, remote fonts, or third-party runtime scripts. The sample demo does not upload files.

Contact

Email privacy@sociobot.in. Do not send a catalog, photo metadata, or license token by email.
