Policy / effective 28 August 2026

Privacy, in plain sight.

CLI data

The CLI runs locally. It reads paths, file names, XMP text, and an optional Lightroom SQLite catalog in read-only/query-only mode. It does not decode image pixels, upload an inventory, access cloud credentials, or include telemetry.

Website data

The website has no analytics, advertising, remote fonts, or third-party runtime scripts. The interactive sample uses recorded data and does not accept your files.

License storage

If you return from checkout with a license or paste one into the restore form, the token is stored in your browser under sb_license:photo-edit-portability-map. A valid/invalid verdict and its check time are cached for up to one day. The token is sent only to Sociobot's license verification endpoint. You can remove it by clearing this site's storage.

Checkout

Sociobot and Dodo are the merchant of record and process purchase, receipt, tax, and refund data under their own policies. This site does not receive payment card details.

Contact

For a privacy request, open an issue in the public project repository without including a license token, catalog, or personal photo metadata.
